# 内部资料

本目录用于追溯设计决策和历史实施过程，不是当前用户的操作说明。这里的文件记录编写当时的背景、路径、命令和实现状态，内容可能已经随着项目变化而过时。

当前行为只以 [项目首页](../../README.md) 和三份正式文档为准：

- [详细使用说明](../USER-GUIDE.md) 负责浏览器操作、素材融合、个人 API、生成和返修。
- [开发技术文档](../DEVELOPMENT.md) 负责架构、模块、数据、配置、接口、测试和提交规范。
- [部署运维手册](../DEPLOYMENT.md) 负责生产配置、Linux、Docker Compose、HTTPS、备份恢复和服务器排障。

请不要把本目录中的历史路径、命令或步骤当作当前操作和部署指南。

- `specs/` 保存“为什么这样设计”的历史设计规格。
- `plans/` 保存“当时如何实施”的历史实施计划。

修改当前行为时，应同步更新对应的正式文档；只有需要追溯新的设计决策或实施过程时，才在这里新增内部规格或计划。
