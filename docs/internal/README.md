# 内部资料

本目录用于追溯设计决策和历史实施过程，不是当前用户的操作说明。这里的文件记录编写当时的背景、路径、命令和实现状态，内容可能已经随着项目变化而过时。

当前使用、部署、运维和开发说明只以 [项目首页](../../README.md) 和 [完整项目手册](../PROJECT-MANUAL.md) 为准。请不要把本目录中的历史步骤当作当前部署指南。

- `specs/` 保存“为什么这样设计”的历史设计规格。
- `plans/` 保存“当时如何实施”的历史实施计划。

修改当前行为时，应先更新正式项目手册；只有需要追溯新的设计决策或实施过程时，才在这里新增内部规格或计划。
