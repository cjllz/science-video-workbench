# 三栏独立滚动设计

## 1. 目标

科普视频工作台桌面端的左侧创建区、中间工作区和右侧历史区目前共同使用页面滚动。当用户在任意一栏滚动时，另外两栏会一起离开原位，影响长表单、脚本编辑和历史记录之间的对照操作。

本次修改让桌面端三栏各自固定在顶部导航下方，并分别滚动。用户把鼠标放在哪一栏，滚轮或触控板就只改变该栏的滚动位置，另外两栏保持原位。

## 2. 范围

修改范围仅包括工作台页面布局、滚动边界和相应验证，不改变：

- 三栏宽度和排列顺序；
- 创建、脚本、渲染、返修、历史和 API 设置业务逻辑；
- 顶部导航、登录页和对话框行为；
- 平板及手机现有两栏/单栏响应式布局；
- 服务端、接口、数据和部署配置。

## 3. 桌面端布局

桌面断点沿用现有 CSS：视口宽度大于 `1180px` 时显示三栏。

已登录的应用外壳占满一个动态视口高度，分成三行：

1. 顶部导航；
2. 可选的全局错误提示；
3. 占据全部剩余高度的三栏工作区。

错误提示不存在时第二行高度为零；出现时工作区自动缩短，因此提示不会遮住内容，也不会让页面产生额外的整体滚动。

工作区和三个面板都允许在 Grid/Flex 收缩链路中缩小到剩余高度。左侧 `.brief-panel`、中间 `.preview-panel` 和右侧 `.history-panel` 分别设置纵向自动滚动，并阻止滚动到边界后继续传递给页面。

每栏预留稳定的滚动条空间，避免某一栏内容从短变长时横向宽度突然变化。横向内容仍由栏内既有表格、时间线等组件自行处理，不新增整栏横向滚动。

## 4. 响应式行为

在 `1180px` 及以下，现有布局会把历史栏放到下一行；在 `760px` 及以下会切换为单列。此时不使用固定视口三栏：

- 应用外壳恢复普通最小页面高度；
- 工作区恢复内容驱动高度；
- 三个面板恢复可见溢出，由页面统一滚动；
- 现有两栏、单栏顺序和宽度保持不变。

该边界避免在平板和手机上形成多个狭窄、难以操作的嵌套滚动区。

## 5. 实现边界

优先通过 `src/client/styles.css` 完成，不增加 React 状态、滚动事件监听、第三方分栏组件或可拖拽宽度。CSS 使用动态视口单位并保留普通视口单位作为兼容回退。

为避免登录页受已登录布局影响，登录外壳使用现有 `.login-shell` 类明确恢复普通文档流。全局错误提示和工作区使用明确的 Grid 行位置，使错误提示是否渲染都不会改变工作区所在行。

## 6. 可访问性与交互

- 保留浏览器原生滚动、键盘 Page Up/Page Down、滚动条和触控板行为；
- 不隐藏滚动条；
- 不捕获或改写滚轮事件；
- 对话框继续固定覆盖整个视口；
- 焦点进入较长表单控件时，浏览器在对应面板内部滚动到该控件。

## 7. 验证

自动和浏览器验证至少覆盖：

1. 桌面视口下应用外壳高度等于视口高度，页面本身没有纵向滚动；
2. 三个面板都可以独立产生纵向溢出；
3. 滚动左栏后，中间和右栏的 `scrollTop` 不变；
4. 滚动中间栏后，左栏和右栏的 `scrollTop` 不变；
5. 滚动右栏后，左栏和中间栏的 `scrollTop` 不变；
6. 显示全局错误时，错误提示可见且工作区仍完整位于视口内；
7. `1180px` 及以下恢复现有页面滚动，不强制三个独立滚动区；
8. 登录页、空工作区、脚本编辑和已有任务预览无明显视觉回归；
9. 现有测试、生产构建和文档检查通过。

## 8. 非目标

本次不实现栏宽拖拽、折叠侧栏、记忆滚动位置、虚拟列表或移动端固定面板，也不顺带重构大型前端组件。
